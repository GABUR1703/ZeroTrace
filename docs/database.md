# Структура базы данных

- `categories` — расширяемый справочник категорий безопасности;
- `scenarios` — ситуации и порядок прохождения;
- `answer_options` — варианты решений и обучающая обратная связь;
- `attempts` — анонимные прохождения с UUID;
- `attempt_answers` — выбранные ответы для аналитики.

Миграции находятся в `backend/src/main/resources/db/migration`.
