# Архитектура

ZeroTrace — монорепозиторий из SPA-клиента, stateless REST API и PostgreSQL. Игровой контент хранится в БД отдельно от интерфейса. Анонимная попытка получает UUID; ответы связываются с ним без сбора персональных данных.

Основные домены: категории, сценарии, варианты ответов, прохождения и ответы прохождения. Итоговый индекс нормализуется в диапазон 0–100, а профиль и рекомендации формируются backend-сервисом. Административная статистика строится только по агрегированным данным.
