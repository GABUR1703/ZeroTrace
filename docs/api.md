# REST API

Планируемые группы ресурсов:

- `/api/v1/scenarios` — активные игровые сценарии без раскрытия баллов;
- `/api/v1/attempts` — начало и завершение анонимного прохождения;
- `/api/v1/attempts/{id}/answers` — сохранение выбранного ответа;
- `/api/v1/admin/statistics` — агрегированная статистика;
- `/api/v1/admin/scenarios` — управление игровым контентом.

Интерактивная спецификация будет доступна через Swagger UI по адресу `/swagger-ui.html`, OpenAPI JSON — `/v3/api-docs`.
