# Игровые сценарии

Сценарии хранятся в PostgreSQL и поставляются миграциями Flyway. Пример переносимого формата находится в `scenarios/scenarios.example.json`.

Каждый вариант ответа содержит балл, максимально возможный балл, последствие, объяснение и рекомендацию. Публичный API не должен отдавать баллы и правильный ответ до совершения выбора.
